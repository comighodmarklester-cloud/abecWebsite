## Changes

- Production uses the configured `App__PublicBaseUrl`. The confirmed Azure origin is the deployment preset; blank or legacy loopback settings in Production resolve to this preset. A configured public custom domain takes precedence. Development launch profiles explicitly use their local server.
- Public URL validation runs on startup and when creating slot emails. It no longer depends on an active HTTP request. Production rejects HTTP public origins, private addresses and malformed origins. Request host/scheme headers do not determine email links.
- Actual notification buttons use `/confirm-slot?token=…` and `/reject-slot?token=…`, with clear **Confirm Slot** and **Reject Slot** labels. Emails fit phone widths and show the exact response deadline in Philippine time.
- Opening either URL remains read-only. The page displays the applicant, course, training date/time, offer time and deadline, then requires an explicit button press to submit the choice.
- Token matching is consistent and case-sensitive on the intent page and submission. Invalid/oversized tokens and expired offers show clear messages. The saved deadline remains 48 hours from the original offer; retries do not extend it.
- Confirmed/rejected responses remain final. Reopening either email button shows the original choice and an explicit already-responded message, without a response form. Opposing POST replays also preserve the original response.

The browser checks require Playwright and Microsoft Edge; the integration harness creates and removes an isolated MySQL database. The existing `scripts/check-system-mobile.cjs` notes describe the local Playwright installation.

## Deployment

Publish the updated application and set Azure's `App__PublicBaseUrl` to the confirmed HTTPS origin. Keep production connection strings and SMTP credentials in hosting settings. Restart/redeploy to load the updated build; the pre-existing local server and live Azure deployment were not changed during these checks.

Already delivered localhost emails cannot be rewritten. The corrected links apply to notifications generated by the updated application; any required replacement notifications must preserve the applicable offer deadline and recorded response.
