## Confirmed findings

### QA-001 - Critical - API HTTP 500 failures (resolved in smoke retest)

The deployed HTML pages are reachable, but every one of the ten tested API requests returned HTTP 500 with this response:

```json
{"success":false,"message":"The server could not complete this request."}
```

This blocks verification of working login, enrollment, course selection, active batches, and address selection. Even empty form submissions fail at the server instead of returning the expected validation response.

**Cause confirmed from the subsequently supplied Azure log:** MySqlConnector rejects the configured connection string with `ArgumentException: Format of the initialization string does not conform to specification starting at index 47.` The same parser failure occurs during startup and API requests. The failure happens before a database connection is attempted. The exact invalid characters cannot be identified without the configured value, which should remain private.

**Resolved in the live smoke retest:** after the user corrected Azure configuration, health reports `ok: true` and `database: true`, and all ten API requests complete with the expected data or validation failure. See the retest results below. The correction format is documented in [the setup guide](../azure-database-setup.md#correct-a-malformed-azure-connection-string).

The log also shows SMTP disabled and the public email-link base URL set to localhost. Email delivery remains unconfigured and unverified.

## Coverage and limits

This report records live HTTP QA of the actual Azure deployment. Static-page HTTP 200 responses do not prove that a page renders or behaves correctly.

Full browser interaction, responsive layout, accessibility, external fonts/scripts, map tile loading, student/admin login through the browser, enrollment completion, email delivery, and authorized administration workflows have not been verified. Browser interaction was unavailable at the time of this report. Successful end-to-end workflows and the authorization issues documented in [the deployment review](../deployment-secret-review.md) still need verification and resolution before release with real records.
